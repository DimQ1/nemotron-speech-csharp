# ADR 0001 — Архитектура LVA поверх nemotron-speech-csharp

## Контекст

ТЗ «Локальный голосовой ассистент» (LVA) требует: always-listening без wake word (семантическая активация), CPU-only ONNX ядро, плагинную архитектуру, MAUI UI с 4 режимами, интерактивного питомца, историю с FTS-поиском. Реализация — в существующем репозитории `nemotron-speech-csharp`, где уже есть ASR-движок.

## Решения

### 1. Структура проектов
Вместо отдельного репозитория — новые проекты `src/LVA.*` внутри текущего, т.к. ASR (`SpeechLib.Nemotron`), аудио и тестовая инфраструктура переиспользуются. Регистрация в `NemotronSpeech.slnx`.

### 2. Токенизатор MiniLM — SentencePiece, не WordPiece
`Xenova/paraphrase-multilingual-MiniLM-L12-v2` использует Unigram-токенизатор. `BertTokenizer` не подходит. Выбран `SentencePieceTokenizer` (Microsoft.ML.Tokenizers 2.0.0) + `sentencepiece.bpe.model`. Это решение зафиксировано в `EmbeddingTokenizerKind` — модели с WordPiece подключаются тем же интерфейсом.

### 3. MAF API
ТЗ ссылалось на `chatClient.CreateAIAgent(...)` — в MAF 1.16 реальный метод `AsAIAgent(...)`. Версии MAF зафиксированы (1.16.0) в `LVA.Plugins.WebSearch.csproj`. MAF спрятан за `ISearchAgent` — замена фреймворка не трогает остальную систему.

### 4. Питомец — SkiaSharp, не Lottie
Прототип задаёт кастомный персонаж (blob с глазами/ушами). Lottie-плеер не даёт программного управления зрачками/деформацией. Выбран SkiaSharp (`CompanionDrawable`) с состояниями из `CompanionStateMachine`. Скин за интерфейсом — заменяем.

### 5. L2 DistilBERT — отложен
Дообучение требует внешнего Python-пайплайна (ТЗ Этап 5). MVP работает на L0-эвристиках + L1 MiniLM + гистерезисе. `IIntentModel` позволяет добавить L2 конфигом без пересборки.

### 6. Целевой фреймворк — net10.0
ТЗ писалось под net9.0, но репозиторий на net10.0 (текущий LTS). Единообразие важнее формального соответствия.

## Последствия

- ✅ Все 49 тестов зелёные; реальный инференс VAD/L1/L3 проверен.
- ✅ Ядро не делает сетевых вызовов (инвариант).
- ⚠ BGE-M3 (570 МБ) — тяжёлый для мобильных; L3 выкл. по умолчанию на Android/iOS.
- ⚠ `Microsoft.Agents.AI` 1.16 — preview-качество; обновление версии = отдельная задача с прогоном интеграционных тестов.
