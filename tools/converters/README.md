# Model Converters

Each subdirectory is an independent converter that can be copied or developed
separately from the applications and shared libraries.

- [NemotronAsr](NemotronAsr/README.md) - NeMo to ONNX export and quantization
  recipes for Nemotron ASR.
- [SortformerStreaming](SortformerStreaming/README.md) - C# streaming-state
  implementation for Sortformer diarization.
