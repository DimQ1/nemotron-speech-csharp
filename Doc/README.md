# Documentation Map

This folder contains internal technical documents grouped by purpose.

## Structure

- `store/imports/`
  - Microsoft Store listing CSV exports and import templates.
  - Use these files for Partner Center listing import/update.

- `store/certification/`
  - Certification artifacts and extracted support files.
  - Use these files for Store/WACK validation evidence.

- `research/asr/`
  - ASR behavior analysis and timestamp investigations.

- `research/onnx/`
  - ONNX/opset conversion and compatibility analysis.

- `plans/`
  - Product and technical implementation plans.
